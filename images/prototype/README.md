# Prototype photography

Created with the built-in image generator for team review, not verified depictions of named artists, events or places. PNG originals retained outside this project; JPEG copies optimized for web use.

Prompt set (all: photorealistic-natural, wide 16:9 editorial images, no logos/text/watermarks, no recognizable real performers or artworks):

- concert.jpg: European outdoor concert at blue hour, crowd silhouettes and distant musicians, amber and teal stage lighting, authentic photographic texture, card-friendly composition.
- theatre.jpg: Historic European theatre interior, velvet seating, softly illuminated stage and distant dancer silhouettes, warm gold and burgundy, realistic texture.
- gallery.jpg: Contemporary European art gallery with abstract paintings and sculpture, visitors viewed from behind, daylight, stone floor and white walls, realistic texture.

Working source photography is retained. PrototypeImage supplies these examples when an image is absent or fails; city/country slots use the existing regional cityscape fallback. CSS background layers also have a local concert fallback.
